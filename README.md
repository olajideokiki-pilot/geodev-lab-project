# Security: Police Stations Accessibility in Ikeja LGA

Which wards in Ikeja Local Government Area (LGA) are more than 3km from a police station?

Built over twelve months with GeoDev Lab Africa, Cohort One.

See the full brief [project_brief](https://github.com/olajideokiki-pilot/geodev-lab-project/blob/main/project_brief.md), which covers the research question, its significance, the required datasets and their sources, and the intended output of the finished system.

## Data Sources (Summary)

| Dataset | Source |
|---|---|
| State Boundary Data | GRID3 NGA - Operational State Boundaries |
| LGA Level Data | GRID3 NGA - Operational LGA Boundaries |
| Ward Level Data | GRID3 NGA - Operational Wards |
| Police Stations | GRID3 NGA - Police Stations |
| Road Data | Extracted using QuickOSM plugin in QGIS software |
